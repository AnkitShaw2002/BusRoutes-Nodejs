AGGREGATION PIPELINE READINESS
================================================================================
The project structure supports MongoDB aggregation pipelines. Models have proper
ref relationships for $lookup stages. When implementing new modules (buses, routes,
trips, bookings, etc.), use this pattern in controllers/services:

  const results = await Model.aggregate([
    { $match: { ... } },
    { $lookup: { from: 'collection', localField: 'field', foreignField: '_id', as: 'joined' } },
    { $unwind: '$joined' },
    { $group: { _id: '$field', count: { $sum: 1 }, avg: { $avg: '$amount' } } },
    { $sort: { count: -1 } },
    { $skip: (page-1)*limit },
    { $limit: limit },
    { $project: { _id: 0, name: '$joined.name', count: 1, avg: 1 } },
    { $addFields: { computed: { $multiply: ['$avg', 1.18] } } }
  ]);

Indexes should be created on frequently queried fields (source, destination, date, status).
